# 方法与阈值（METHOD）

本文说明每个判定是怎么做出来的，以及阈值取在哪。**代码是唯一事实来源**，本文若与代码冲突以代码为准（`scripts/pk/`）。

## 1. 数据流

```
case.json
  ├─ 稿件 → 正文 / 文末列表 / 正文引用标记（带字符偏移）
  └─ 文献库 → 记录（字段归一 + 每条 provenance）
        ↓
  链接：条目 ↔ 记录（DOI > arXiv > 题名 > 年+卷+页）
        ↓
  去重：两两比较 → merged / distinct / needs_review（带 basis 与 veto）
        ↓
  编号：以实体为单位，按正文首现顺序 1..N
        ↓
  重写：正文标记 → 文末列表 → 图表注 → 附录（同一遍完成）
        ↓
  核验：闭合世界 / 字段规则 / DOI 解析（可降级） / 论断—文献匹配
        ↓
  result.json（契约字段平铺）+ 报告 + 账本
```

## 2. 字段归一

- 中英文字段名都映射到同一内部字段（`title` / `title_alt` / `authors` / `year` / `venue` / `volume` / `issue` / `pages` / `doi` / `arxiv` / `type` / `abstract`）。
- DOI 从任意字段或 URL 中提取并规范化（去 `https://doi.org/`、`doi:` 前缀、尾随标点）。
- 年份只保留 19xx/20xx 四位数；`type` 映射为 GB/T 7714 标识符（J/M/C/D/R/A/…）。

## 3. 条目 ↔ 记录 链接

| 证据 | 分数 |
|-|-|
| DOI 相等 | 0.99 |
| arXiv id 相等 | 0.97 |
| 题名相似 ≥0.90（含中英双语字段比较） | 0.86–0.95（同年 +0.03） |
| 题名相似 ≥0.70 且 年 或 卷 一致 | 0.70–0.77 |
| 年+卷+页 三者一致 | 0.72 |
| 卷+页 一致且题名 ≥0.55 | 0.66 |

低于 **0.55** 视为未链接。同分时按记录质量决胜：**正式发表 > 预印本**、有 DOI > 无、字段更全 > 更少。这条规则的作用是防止「同一篇文献的预印本记录抢走正式版的链接」。

## 4. 去重判定

比较**先否决、后合并**。

**否决（判 different，任何一条成立即否决）**
| 条件 | 理由 |
|-|-|
| 双方都有 DOI 且不等 | 不同作品 |
| 双方都有 arXiv 且不等（且无共同 DOI） | 不同作品 |
| 双方都有卷且不等 | 同一作品不会换卷 |
| 年份差 ≥2 且题名相似 <0.97 | 不同作品 |
| 第一作者不同且题名相似 <0.80 | 不同作品 |
| 页码不同且题名相似 <0.90 | 不同作品 |
| 题名相似 <0.55 且无标识符桥梁 | 不同作品 |

**合并（按优先级）**
| 规则 | 置信度 |
|-|-|
| DOI 相等 | 0.99 |
| arXiv 相等 | 0.97 |
| 命中同一条库记录 | 0.95 |
| 预印本 ↔ 正式版（题名 ≥0.86、作者重合 ≥0.5、年差 ≤1、一方无卷） | 0.88 |
| 题名 ≥0.92 且 年一致/差1 且 作者重合 ≥0.5 | 0.90 |
| 跨语言（中英题名）作者重合 ≥0.5 且同年，**另有卷/页/刊名至少一项佐证** | 0.82 |
| 跨语言但只有作者+年 | **不合并**，`needs_review` |
| 题名 0.75–0.92 | `needs_review` |

**合并后填字段**：缺失字段从其他成员补齐，逐字段记 `field_provenance`；成员间不一致记 `field_conflicts`。

**为什么必须留 `needs_review`**：题面明确要求「避免误合并同名作者的不同文献」。宁可交一条待确认项，也不制造一条错误合并——前者可复核，后者是无声的数据损坏。

## 5. 编号（编得顺）

- 编号**不是**存储状态，而是派生量：`number = 该实体在正文首次出现的位置序`。
- 任何插入/删除/调序/合并之后只做一次重算，然后从右向左重写所有标记（保证偏移不失效）。
- 连续数字压缩：3 个及以上连续 → `1-3`；2 个 → `1,2`。
- 覆盖四个面：正文、文末列表顺序、图表注、附录——因为扫描范围就是全文，不区分章节。
- 未引用但存在于列表的条目：编号排在已引用之后并标 `uncited`（不删，便于复核）。
- 标记无法解析到条目：**原样保留**并记 `dangling_marker`（不静默删除引用）。

### 幂等性怎么保证

```
pass1 = pipeline(原文)
pass2 = pipeline(pass1.manuscript)
断言 pass1.manuscript == pass2.manuscript（逐字节）
```

稳定的三个前提：①渲染只依赖字段（同实体同字符串）；②标记重写后仍能被同一解析器识别（`[n]` / 上标 / `(Author, Year)`）；③无法从元数据安全重建的条目（无库记录或字段过薄）**回退为原文照抄**，不再压缩信息。这一条是整个幂等性的关键——用不完整元数据重排条目会导致第二次运行产生不同文本。

## 6. 核验（对得上）

三层证据，互不替代：

1. **闭合世界**：每条引用必须落到提供的文献库记录上。落在稿件文献表里、却不在库里的条目 = 最强编造信号。
2. **字段规则**：题名/作者/年/来源缺失、DOI 语法、年份越界（> 当前年 +1，< 1800）、页码起止颠倒、成员字段冲突。
3. **DOI 解析**（可选）：`https://doi.org/api/handles/<doi>`，超时 2.5s，最多 10 个。
   - `resolved` → info
   - `not_found` → `DOI_NOT_REGISTERED`（**中**强度，`needs_review`，**不等于编造**）
   - 任一网络异常 → 立刻停止后续请求，整轮 `offline_degraded` + `network_unavailable: true`，继续用前两层判定。

**论断—文献匹配**：仅当材料提供摘要/全文时计算（关键词重合度 + 数字一致性）；没有证据文本一律 `evidence_insufficient`。判定阈值：重合 ≥0.34 且数字全部命中 → `supported`；≥0.18 → `weak`；否则 `mismatch`。

**判定合成**：任一高强度问题或 `mismatch` → `fail`；任一中等强度或 `weak` → `needs_review`；否则 `ok`。

## 7. 状态

| status | 含义 |
|-|-|
| `success` | 全部引用可核验、编号连续且幂等、无高危问题 |
| `partial` | 有产出但存在缺口（疑似编造、库外条目、fail 判定、非幂等、阶段异常） |
| `unable` | 读不到稿件 |

`status_reason` 逐条列出原因，不写空话。
